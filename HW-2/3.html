Explaination : text-shadow: 4px 4px 6px rgb(255, 142, 5) ;

  • 4px value is for moving the shadow towards right from the original tag.
  • 4px value is for moving the shadow towards bottom from the original tag.
  • 6px value is for bluring the shadow by 5px.
  • the 4th value is for giving the color to the shadow.
